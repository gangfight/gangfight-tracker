# Gangfight: Tracker

This repository is the central place to track everything around Gangfight. It
contains no code, it is used purely as an issue and feature tracker, including
discussions, for the whole project.

## Issues

Use [issues][issues] to report bugs or problems you ran into while playing,
and to track concrete work. Please search existing issues first and add to them
instead of opening a duplicate.

## Features

Have an idea for the game? Open an [issue][issues] describing the feature and
the problem it solves, or start a conversation in [discussions][discussions]
first if you want to talk it through before it becomes a concrete proposal.

## Discussions

[Discussions][discussions] are the place for questions, ideas, feedback and
general conversation about Gangfight that is not a bug report or a defined
piece of work.
